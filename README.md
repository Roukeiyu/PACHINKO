# PACHINKO · PON PON · 弹一点小快乐

一个可爱、轻松的网页柏青哥游乐场。无需账号、后端或 API 密钥。

## 网页直接玩（推荐）

GitHub Pages 首次部署成功后，直接打开 **[PON PON 在线游戏](https://roukeiyu.github.io/PACHINKO/)** 即可游玩。手机、电脑都可以；玩家无需下载项目或安装 Node.js。

仓库已配置自动发布：推送到 `main` 后，GitHub Actions 会安装依赖、构建并部署游戏。源码仓库页面用于查看代码，游戏链接才是可直接游玩的网页。

仓库管理员首次开启：

1. 打开 [Settings → Pages](https://github.com/Roukeiyu/PACHINKO/settings/pages)。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 到 [Actions](https://github.com/Roukeiyu/PACHINKO/actions/workflows/pages.yml) 选择 **Deploy game to GitHub Pages → Run workflow → main → Run workflow**。也可重新运行之前因 Pages 尚未开启而失败的工作流。
4. 等待 `build` 和 `deploy` 均成功，再打开游戏链接。首次发布前或发布失败时，链接可能返回 404。

在线版最高分与设置保存在当前浏览器中，不上传 GitHub。后续更新只需推送代码，无需重复配置 Pages。

## 从 GitHub 获取并运行

克隆本仓库或通过 Code → Download ZIP 下载并解压。安装 Node.js 24 LTS 后，在项目目录运行：

```sh
npm ci
npm run dev
```

Windows 也可直接双击 `start-dev.cmd`，首次自动安装依赖并打开浏览器。仓库不提交 `node_modules/` 和构建产物 `dist/`；从 GitHub 下载后，如需使用 `start-game.cmd`，请先运行 `npm ci` 和 `npm run build`。下方的预构建压缩包说明适用于聊天中提供的完整项目包。

## Windows 本地使用（无需 GitHub）

1. 把压缩包内容解压到 `D:\Pachinko`，确保该目录下直接包含 `package.json` 和 `start-game.cmd`。
2. 安装 Node.js 24 LTS（如果已经安装则跳过）。
3. 双击 `start-game.cmd`：使用包内已构建的 `dist/`，自动打开浏览器，无需安装 npm 依赖，运行时不需要联网。关闭命令窗口或按 Ctrl+C 停止。
4. 要修改源码，双击 `start-dev.cmd`：首次会通过 npm 安装依赖（需要联网），之后启动支持热更新的开发服务。无需 Git 或 GitHub 账号。

也可以在 PowerShell 中开发：

```powershell
cd D:\Pachinko
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --open
```

修改源码后执行 `npm.cmd run build` 更新 `dist/`，再通过 `start-game.cmd` 运行最新构建。此压缩包不包含 `.git` 或 Linux 的 `node_modules`；源码、锁文件、构建文件、测试及验证截图均保留。浏览器内原有的最高分和设置属于浏览器本地数据，不随文件迁移。

## 玩法

- 弹珠从右下角的弹簧轨道向上发射，经顶部斜壁弹入球台。手动模式的蓄力按钮横贯底部。按钮左上角是一颗同样深绿、同样厚边的圆形倍率按钮，点按循环。×1 不写数字，只留一颗浅点；×2、×4、×8 写出倍数，金色描边随倍数加重，并跟着昼夜变色。按住蓄力按钮、球台中间、右侧弹簧或空格键，都从 0% 开始，以指数曲线逐渐趋近满蓄力，先快后慢；约 0.15 秒达 82%、0.45 秒达 99.4%，0.6 秒达到 99.9% 时直接判为 100%。显示百分比保留至一位小数，不提前四舍五入到 100%；松开时按同一曲线计算实际发射力度，松手或取消后归零。轻点仅轻微弹跳，0% 不产生向上弹力；手动蓄力不沿用自动弹射的力度。
- 蓄力时右侧待发小球外的淡金光圈逐渐收拢，100% 时从球心透出彩虹日辉；满蓄力后再长按 0.9 秒，辉光渐强渐大，游乐场逐渐轻微抖动。总长按 1.5 秒后松手，发射器以约 90 毫秒间隔快速送出 5 颗满力度弹珠，每颗独立碰撞和结算；提前松手仍发射一颗。轻柔模式保留状态提示与五球奖励，使用静态淡光并取消抖动。取消手势、打开设置、切到后台或窗口失焦均清除蓄力，不会意外发射。
- 松手时每颗弹珠只施加一次与蓄力成正比的初速度，没有保底大弹力、持续助推或速度保持。1% 只会微微弹起，力度不足时自然落回并回收；充分蓄力才能飞得更高。飞越回流口后落回轨道的弹珠，会被单向拦截坡导向左下方出口，重新进入球场。
- 在设置内开启「自动弹射」后，力度滑块会在原蓄力按钮的位置出现，可调 1%–100% 力度，每 1.1 秒按所选力度尝试发射一颗；轨道占用时自动等待。在设置内关闭自动弹射后恢复蓄力按钮，自动力度与手动蓄力相互独立。
- 球台包含 3 个主动弹力鼓、4 块斜挡板、1 根摆动挡杆、2 个菱形弹力块、25 个弹钉和 2 个固定弹射钉。左右鼓之间原来并排的两颗弹钉合并为中点上的一颗。固定弹射钉位于上方标题上沿与下方两个菱形之间的中线上，每局及所有槽位下均存在，命中后主动弹开弹珠并触发闪光和卡农音符。弹钉采用固定坐标，以中央反弹点所在的竖直中线为轴，左右同高度镜像对称、均匀分布，刷新页面或切换槽位都不会重新随机排列；留出通球间隙并避开移动障碍的完整活动范围。卷轴正上方、粉色弹射钉左右那两颗弹钉已去掉。左侧增加向内倾斜的护栏；左上与右下斜挡板保持角度，沿各自长边的斜向轴线平滑往返，碰撞位置同步移动，打开设置时一起暂停。下方两个菱形各自上下 ±20px、周期 3 秒，左右相差半个周期，并绕自身中心反向旋转，4 秒一圈。位移和旋转都计入碰撞速度，碰到的弹珠会被推开；打开设置、小游戏或切到后台时跟物理一起停住。
- 保留右侧完整发射通道、隔墙和单向回流口，去掉「惯性飞行」文字及原助推截止线。
- 左鼓和右鼓以中央鼓的竖直中线为轴，在同一高度左右镜像固定；刷新、槽位切换都不改变位置。左上反弹点每命中 5 次，朝随机方向赠送真实弹珠，颗数等于触发它的那颗弹珠的 ×N（×1 仍是 1 颗）；右上反弹点每命中 5 次，将中央反弹点的外观和碰撞半径同时放大为 1.5 倍，持续 10 秒，再次触发会刷新时长，不另加库存，进度仍是每次 +1。中央反弹点的进度按命中弹珠的 ×N 累加，目标仍是 30。兔子鼓、熊鼓和两块紫色菱形每撞上一次另加 1 分，中央猫鼓平时加 2 分、放大的 10 秒里加 5 分，再乘这颗弹珠自己的倍率（发射 ×N 乘它拾到的星星，和球边的环同一套，不含老虎机全场倍率）。同一颗球贴着同一块连撞时，150 毫秒内只加一次。鼓的 5 次、30 次进度不变。
- 中央反弹点的进度走到 30，从 12 点钟方向开始，按顺时针每 30 度发射一颗普通 ×1 弹珠。球仍出现在对应钟点外侧，飞出方向是半径向外再顺时针偏 15°：正上方如果笔直射出，会在中心弹钉和鼓面之间竖直弹个不停，这 15° 让它带上向右的速度离开鼓顶。×1 球触发时是 12 颗，约 0.92 秒发完；×N 球触发时是 12×N 颗，没有颗数上限，仍按同一间隔排队发出，不会一次塞进场。这些球可以继续碰撞、触发奖励和入槽计分，但它们自己是 ×1，下一次赠球不再乘上去。
- 左下蓄球罐通过朝上的真实入口吸收弹珠，存满 20 颗后清空本次库存，从球台顶部释放真实弹珠。放出来的颗数是 20 乘上把罐子装满的那颗弹珠的 ×N。先放出的 20 颗保留存入时的星星倍率，多出来的是普通 ×1。自己打出的球存进去仍算进剩余球数，可以再拿来发射。赠球（鼓、时钟、罐子落下的淡紫球）只把罐子计数加一，不退回剩余球数。罐子存满后的落下颗数不变。顶部开口与底部槽位一一对应，分轮随机出球，每轮覆盖所有开口，因此各开口的出球数量最多相差一颗；出球时间和位置稍有随机偏移，弹珠自然下落并参与球台碰撞、奖励及入槽计分。被存入的弹珠当时不计分，释放时保留该球已有的星星倍率。库存、待发弹珠、出球口闪光都随游戏暂停；切换槽位保留库存和未发弹珠，并更新对应开口。
- 三格分开的小方框在球台下半部正中，对着中间的 LUCKY 槽、贴在计分列上方，没有外框，也没有 LUCKY PON 标题。中央大鼓下移到它们原来的位置，和摆杆之间留出大约一颗球的空隙。方框本身不挡球。方框下面只有一条进度条和 `进洞数/50`。每格按权重抽取星星、弯月、太阳、行星、彗星（各 18）和弹珠（10）。这些图案是天文小图标，和底部槽位的水果不是同一套。底部槽位与秘密洞每累计进洞 50 次，三格一起转动一次，多次达标排队保留；吸收进蓄球罐、回收与碰撞不计进洞。正中 LUCKY 槽每进一颗球，随机一格单独转一次，另外两格保持当前图案；转动途中再进 LUCKY 会排在同一个队列里，不会打断正在转的那一格。两侧印着 LUCKY 的高倍槽不转。单格停下后，只有图案变了，并且这一格参加了新的两同或三同，或者新停在弹珠图案上，才按当前三格发奖。图案没变，或者只换了旁边那一格，不会把已经亮着的组合再发一次。两格相同触发全场进洞得分 ×2，持续 3 分钟；三格相同触发 ×5，持续 1 分钟，三格不同不加成。停住的弹珠图案另发球：1 个 +1，2 个 +10，3 个是大奖 +100，再乘上让这格转起来的那颗弹珠的 ×N，并有单独的庆祝。老虎机 0/50 的进度仍是每次进洞 +1。三颗弹珠同时也会触发 ×5。倍率在入洞结算时生效，与单球星星倍率相乘；球台标题、各槽位和秘密洞奖励同步显示。重复中奖刷新对应时长，×5 优先，结束后恢复尚未到期的 ×2；计时、转动和队列随游戏暂停，槽位切换保留。刷新默认重新开始这一局；只有 GM 的「保持分数模式」打开时，刷新才会接着球数、积分和槽位。老虎机进度无论哪种刷新都重新计。
- 右侧「奖励进度」顶部用大号数字显示「全场当前倍率」，只跟老虎机两同 ×2 或三同 ×5。没有老虎机加成时是 ×1，下面不写星星倒计时，也不写发射倍率。老虎机限时加成会把剩余时间写在数字下面，倍率变化时数字轻轻跳一下。场上的倍率星星，以及拾到星星的那颗弹珠，各自标着本球倍率，不写进这张卡片。卡片里先是老虎机当前三格和进洞次数（有老虎机倍率时，进度条下面只留剩余时间），然后是三个反弹点和蓄球罐。秘密洞奖励仍在球台顶栏，倍率星星仍画在球台上，这两项不再各占一行。宽屏时这张卡片在快乐使用说明下面。收集册和排行也在这一栏，紧挨着「不用赶路，弹一会儿也很好」。手机没有侧栏，这两个按钮和同一张奖励进度放在球台与发射按钮下面。计数在当局内累计；打开设置或切到后台会暂停奖励计时，切换槽位会取消未完成的弹珠发射序列。刷新默认重新开始这一局；只有 GM 的「保持分数模式」打开时，刷新才会接着球数、积分和槽位。鼓的计数无论哪种刷新都重新开始。
- 左侧为三角弹射平台，每撞击一次便在完整 360° 范围内随机选择新角度，与上次朝向至少相差 25°，并把当前弹珠沿新方向弹出。平台尖角与箭头显示弹射方向，撞击伴随闪光、粒子和卡农音符，不吞球、不计秘密洞分数。左上斜挡板向右移动，拦截从上方向三角平台斜落的路线。
- 右侧秘密洞贴在发射道内侧那条绿色斜挡的左下端，入口仍朝向左下约 45°（7:30，从正上方顺时针 225°）。环上的缺口和挡墙一起转过去，2D 和 3D 相同。真实进入后奖励 500 分。机会由轨迹决定，没有随机拒绝。同一波指第一次进洞之后、小游戏开始之前的排空等待：台上还没落定的球（包括同一次五连发里的其他球）若再进秘密洞，这次秘密洞得分 ×2。进洞奖励和小游戏结算都翻倍，而且只翻这一次；第三颗及以后仍按 ×2 计，不再叠成 ×4，也不再另开一局小游戏。第二颗进洞时提示「双球入洞！秘密洞得分 ×2」，小游戏弹窗显示 ×2，完成页写下翻倍后的分数。
- 设置可调整声音、震动、自动弹射、昼夜变化、3D 模式和「全屏幕宽度」。全屏幕宽度默认关闭，记在本地：打开后桌面页面去掉最大宽度和两侧留白，铺满窗口高度，球台在侧栏旁边按原来的宽高比缩放，改窗口大小会重新适配。窄屏和横屏小窗仍用原来的手机布局。侧栏分数和剩余球数留在画面里。槽位不再手选，随快乐积分自动增加。动物场景固定使用兔子、熊和猫；收集册有独立按钮和弹窗，不再放在设置中。震动默认开启并单独保存，静音不会关掉它。
- 手机竖屏的快乐积分单独占顶部一行，数字用等宽数字并留出到 999,999,999 的宽度，避免分数变长时整栏换行跳动。状态和秘密洞在下一行。收集册、排行和奖励进度在球台与发射按钮下面，不放进顶栏。
- 排行榜只显示前 20 名。预置 20 条固定成绩，第 1 名 101220，第 20 名 50010，中间分数都是 10 的倍数并且递减。每一局有自己的 run id。中途不再弹名字。本局结束时，若快乐积分达到 50000，或高于当前榜上的第 20 名，才弹出街机式名字输入；跳过则不提交。提交一次就是这一局的最终分，之后不再改写。若构建时配置了 `VITE_LEADERBOARD_URL`（Worker 的根地址），确定名字时请求一次 `/submit`，打开排行榜时请求 `/top`，请求不带 token，失败则继续用本地榜。超出前 20 的记录仍留在本地，只是不显示。Worker 的部署步骤在 `worker/README.md`。
- 场内始终最多一颗倍率星星：普通金色 ×2 星星持续 30 秒，超时未拾取便销毁并换位置生成。每累计拾取 10 颗普通星星，下一颗变为紫色 ×5 星星，仅持续 10 秒，拾取或超时后恢复普通星星；紫色星星与超时不计入普通拾取次数。星星旁显示倒计时，打开设置或切到后台一起暂停。拾取后 0.5 秒出现下一颗，避开障碍物及其运动范围。拾取会将当前弹珠的结算倍率乘以星星倍率，可连续叠加，并和这颗弹珠自己的发射 ×N 分开相乘。这颗弹珠自己的倍率（发射 ×N 乘上已拾取的星星）画在球的外圈：×1 是一圈细的浅金，×2 是橙色圈，×4 带一层柔和光晕，×8 是橙红色外圈再向外发光；高于 ×8 仍用这一圈，光晕略强一点。2D 和 3D 都不再在球旁边写 ×N。赠出的淡紫球仍用淡紫球心，外圈改成同一套档的紫色：×1 细紫，×2 更深更饱和的紫，×4 深紫加柔光，×8 是亮紫红外圈再向外发光；高于 ×8 仍用这一圈，光晕略强一点。鼓和时钟送出的球自己是 ×1，触发它的 ×N 只决定颗数；罐子放出的球保留存入时的星星倍率，不带发射 ×N。赠球自己拾到星星也乘这个倍率，入槽、秘密洞和撞鼓加分都用它。赠球进罐子仍只加计数，不退回剩余球。其他弹珠不受影响，新弹珠从 ×1 开始。全场倍率卡片不因星星变化。白天、黄昏和清晨用实色星体、深色描边、较小光晕和带描边的倒计时；夜间保持加法混合的发光。2D 和 3D 同一套区分。3D 星星贴图按设备像素比放大到最多 2 倍，并开启 mipmap 与各向异性过滤。

- 手机顶部只保留与 Logo 同排的短标题，省去独立介绍与底部装饰区；球台按可用屏幕高度缩放，尽量让全局和操作区一屏显示。H5 支持触控蓄力、松手发射、取消手势、横竖屏布局和安全区。整个游戏界面禁用长按选字、图片拖动与长按菜单，同时保留页面滚动、滑块操作和浏览器缩放。

### 弹弓拆拆乐

拆拆乐是俯视平台：底部炮台固定在中心，拖动调整向上的射击方向，松手发射，也支持点按发射。固定边框内有 5×5 共 25 块正方形自由碰撞方块，平台平面重力为零，用阻尼让滑动逐渐停下。整块离开边框才计一次，每块 180 分；旋转方块按真实顶点与矩形平台做分离轴判定，区内晃动和仅中心越界不算。离台方块立即移出碰撞，保持自身中心与角度，在 600 毫秒内逐渐缩小淡出，模拟向平台下方掉落。30 秒内将 25 块全部推出才过关，提前结算另加 1200 分；弹珠不限量，每 0.4 秒补发。命中有撞击闪光和弹珠尾迹，出界飘分，需要换角度击打不同位置。时间到保留得分；挂机、空发不算有效操作。GM 和秘密洞仍使用原有结算与返回流程，取消手势、退出及重试会清理物理。秘密洞随机池和 GM 均已移除独立的弹珠瞄准，保留其余五款小游戏。

`npm run test:mini-games` 包含新增的真实物理规则和桌面、320/390px 触屏、转横屏浏览器回归，截图输出至 `test-results/sling-*.png`。测试模拟手机浏览器，未在真实手机上验收。

五款小游戏在 GM 状态下均显示「结束本局」，按当前已得分结算一次。非 GM 不显示、不占布局位置，处理入口也检查实时 GM 状态。结束或返回会取消拖动捕获、按键、动画和待执行的特效计时器，重开不沿用上一局。打地鼠每个圆盘在转到 90° 的同一帧清掉黄色命中提示与旧图案，后半程统一底色；轻柔模式在淡出中点切换。

接星星底部设独立滑动／点按操作区，小游戏界面及其背景的非按钮区域也能控制挡板；画框外横坐标钳制到两侧，整个挡板留在框内。支持指针捕获、取消、多指隔离和缩放坐标，按钮不参与挡板操作。成功接取只在挡板上方绽放小星光，没有全屏闪白；最多 15 个粒子，轻柔／减少动态模式用单颗淡出。炸弹保留扣分并用挡板局部红色受伤反馈。相关浏览器截图输出至 `test-results/star-controls-*.png` 和 `test-results/mole-flip-*.png`。

## 实现

Vite + 原生 JavaScript / Canvas + Matter.js，每秒 120 次固定步长物理模拟，渲染跟随屏幕刷新率。`src/physics.js` 管理球台与计分，`src/renderer.js` 绘制球台，`src/main.js` 管理界面和输入。`src/time-flow.js` 管理独立的昼夜时钟与颜色插值，CSS 变量、SVG 和 Canvas 共用配色；弹珠亮度和星星奖励识别色保持可辨认。`src/music.js` 用 OfflineAudioContext 本地生成原创 A/B 配乐，折叠尾音并由 AudioBufferSource 精确衔接与循环。Web Audio 实时合成弹射、弹力鼓、挡板、落袋与秘密洞音效，不依赖外部图片、字体或音频请求。应用可静态部署 `dist/`。

### 2D / 3D 显示模式

- 默认使用原有 2D 画面，设置只保留「3D 模式」开关，可切换立体球台并自动保存。旧镜头角度设置不再使用；镜头保持固定视角，蓄力与奖励时只做上下左右位移，不旋转镜头。
- 3D 球台使用 Three.js/WebGL 透视相机（`VIEW_FOV` 40°，俯仰 `VIEW_PITCH_DEG` 36°，距离 `VIEW_DISTANCE` 1600，视线落点 `VIEW_LOOK_Y` -40。上一版是 44°、距离 1550、落点 -50；更早是 14° 正交、距离 1400）。围栏高度 `WALL_HEIGHT` 58，斜挡板高度 `RAIL_HEIGHT` 36。远边大约是近边宽度的七成，整台、底部球洞和发射器仍落在画面内。棋盘外不再摆动物和水果。所有物理装置直接使用原有 Matter.js 坐标与角度，加高只影响模型。切换模式仅替换画布和释放渲染资源，保留在途弹珠、积分、奖励和计时状态。
- 手机竖屏（宽度不超过 740px）去掉球台卡片左右留白。标题和积分栏收矮，蓄力条贴在底部安全区，球台用顶栏和蓄力条之间的空间，按宽和高里更紧的一边缩放（2D 仍是 760:900）；宽不够时球台在这段高度里垂直居中。3D 画布铺满这段高度，不再锁死 1.24。画布比 1.24 更高时，相机会略微放平（俯仰最低约 10°，距离仍是 `MOBILE_VIEW_DISTANCE` 1150），让球台在这段高度里居中，近边左右大约各留 5px，整台和蓄力晃动仍留在画面内。桌面和横屏仍是俯仰 36°、视角 40°、落点 -80，画布高宽比 1.24。矮竖屏会按高度缩小以免挡住发射键。发射和弹簧的触摸区域继续按画布投影计算。切换倍率时的提示出现在蓄力条上方，不再盖住按钮下面的说明。
- 台面上的倍率星星不再使用挤出的立体模型。夜间仍是带光晕的发光星形；白天、黄昏和清晨改成实色内核、深色描边和较小的光晕，倒计时文字带描边。被弹珠触发时原地爆闪。位置、半径和拾取判定不变。
- 2D 与 3D 的蓄力、奖励震动均只让镜头上下左右位移，始终不旋转镜头、台面或 UI。满蓄力后 0.9 秒内逐渐增强位移震动，彩虹蓄满（总长按 1.5 秒）时蓄力震动最大横向 5.5、纵向 4 个台面单位（原先 11 和 8 的一半，常量在 `src/scene-motion.js` 的 `CHARGE_SHAKE_SCALE`）；继续长按保持此强度。奖励震动仍是横向 7、纵向 5，不随蓄力减弱。UI 仅横向 0.45、纵向 0.3 像素。轻柔模式关闭这两类镜头震动。3D 的空间感来自透视和加高挡板，蓄力位移幅度没有调回。
- 移动端发射区域随场景投影对齐；不支持 WebGL 的设备保持 2D 画面。模型与字体贴图均随网站打包，无远程模型加载。
- 手机震动在 `src/haptics.js`：碰撞 `HAPTIC_COLLISION_MS` 12ms，速度低于 `HAPTIC_MIN_SPEED` 2 或间隔短于 `HAPTIC_MIN_INTERVAL` 50ms 的碰撞不响；普通进洞 28ms，Lucky 55ms，秘密洞是 `HAPTIC_JACKPOT_PATTERN` `[40, 30, 80]`。更强的一档会换掉还在响的弱震动，弱的不会打断强的。iOS Safari 没有 `navigator.vibrate`，调用会静默跳过。
- `npm run test:3d` 验证默认 2D、开关与保存、切换保留物理状态、真实三维几何、场景角度与 UI 位移限制、触控投影、奖励放大、释放旧模型及不支持 WebGL 时回退。`npm run test:charge` 在两种模式下覆盖昼夜和轻柔模式的长按发射。

- 场景固定为动物游乐园，取消甜品、花朵和主题切换。旧存档中的主题选择不再使用，收集数量、最高分和其他设置继续保留。收集册与设置由独立按钮打开独立弹窗；任一弹窗打开时暂停球台并取消蓄力，关闭后继续。
