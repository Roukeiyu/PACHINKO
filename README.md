# PACHINKO · PON PON · 弹一点小快乐

一个可爱、轻松的网页柏青哥游乐场。无需账号、后端或 API 密钥。

## 网页直接玩（推荐）

GitHub Pages 首次部署成功后，直接打开 **[PON PON 在线游戏](https://roukeiyu.github.io/PACHINKO/)** 即可游玩。手机、电脑都可以；玩家无需下载项目或安装 Node.js。

仓库已配置自动发布：推送到 `main` 后，GitHub Actions 会安装依赖、构建并部署游戏。源码仓库页面用于查看代码，游戏链接才是可直接游玩的网页。

仓库管理员首次开启：

1. 打开 [Settings → Pages](https://github.com/Roukeiyu/PACHINKO/settings/pages)。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 到 [Actions](https://github.com/Roukeiyu/PACHINKO/actions/workflows/pages.yml) 选择 **Deploy game to GitHub Pages → Run workflow → main → Run workflow**。也可重新运行之前因 Pages 尚未开启而失败的工作流。
4. 等待 `build` 和 `deploy` 均成功，再打开游戏链接。首次发布前或发布失败时，链接可能返回 404。

在线版最高分与设置保存在当前浏览器中，不上传 GitHub。后续更新只需推送代码，无需重复配置 Pages。

## 从 GitHub 获取并运行

克隆本仓库或通过 Code → Download ZIP 下载并解压。安装 Node.js 24 LTS 后，在项目目录运行：

```sh
npm ci
npm run dev
```

Windows 也可直接双击 `start-dev.cmd`，首次自动安装依赖并打开浏览器。仓库不提交 `node_modules/` 和构建产物 `dist/`；从 GitHub 下载后，如需使用 `start-game.cmd`，请先运行 `npm ci` 和 `npm run build`。下方的预构建压缩包说明适用于聊天中提供的完整项目包。

## Windows 本地使用（无需 GitHub）

1. 把压缩包内容解压到 `D:\Pachinko`，确保该目录下直接包含 `package.json` 和 `start-game.cmd`。
2. 安装 Node.js 24 LTS（如果已经安装则跳过）。
3. 双击 `start-game.cmd`：使用包内已构建的 `dist/`，自动打开浏览器，无需安装 npm 依赖，运行时不需要联网。关闭命令窗口或按 Ctrl+C 停止。
4. 要修改源码，双击 `start-dev.cmd`：首次会通过 npm 安装依赖（需要联网），之后启动支持热更新的开发服务。无需 Git 或 GitHub 账号。

也可以在 PowerShell 中开发：

```powershell
cd D:\Pachinko
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --open
```

修改源码后执行 `npm.cmd run build` 更新 `dist/`，再通过 `start-game.cmd` 运行最新构建。此压缩包不包含 `.git` 或 Linux 的 `node_modules`；源码、锁文件、构建文件、测试及验证截图均保留。浏览器内原有的最高分和设置属于浏览器本地数据，不随文件迁移。

## 玩法

- 弹珠从右下角的弹簧轨道向上发射，经顶部斜壁弹入球台。手动模式只显示蓄力按钮：每次按下按钮、右侧弹簧或空格键，都从 0% 开始，以指数曲线逐渐趋近满蓄力，先快后慢；约 0.5 秒达 82%、1.5 秒达 99.4%，2 秒达到 99.9% 时直接判为 100%。显示百分比保留至一位小数，不提前四舍五入到 100%；松开时按同一曲线计算实际发射力度，松手或取消后归零。轻点仅轻微弹跳，0% 不产生向上弹力；手动蓄力不沿用自动弹射的力度。
- 蓄力时右侧待发小球外的淡金光圈逐渐收拢，100% 时从球心透出彩虹日辉；满蓄力后再长按 3 秒，辉光渐强渐大，游乐场逐渐轻微抖动。总长按 5 秒后松手，发射器以约 90 毫秒间隔快速送出 5 颗满力度弹珠，每颗独立碰撞和结算；提前松手仍发射一颗。轻柔模式保留状态提示与五球奖励，使用静态淡光并取消抖动。取消手势、打开设置、切到后台或窗口失焦均清除蓄力，不会意外发射。
- 松手时每颗弹珠只施加一次与蓄力成正比的初速度，没有保底大弹力、持续助推或速度保持。1% 只会微微弹起，力度不足时自然落回并回收；充分蓄力才能飞得更高。飞越回流口后落回轨道的弹珠，会被单向拦截坡导向左下方出口，重新进入球场。
- 在设置内开启「自动弹射」后，力度滑块会在原蓄力按钮的位置出现，可调 1%–100% 力度，每 1.1 秒按所选力度尝试发射一颗；轨道占用时自动等待。在设置内关闭自动弹射后恢复蓄力按钮，自动力度与手动蓄力相互独立。
- 球台包含 3 个主动弹力鼓、4 块斜挡板、1 根摆动挡杆、2 个菱形弹力块、28 个弹钉和 2 个固定弹射钉。固定弹射钉位于上方标题上沿与下方两个菱形之间的中线上，每局及所有主题、槽位下均存在，命中后主动弹开弹珠并触发闪光和卡农音符。弹钉采用固定坐标，以中央反弹点所在的竖直中线为轴，左右同高度镜像对称、均匀分布，刷新页面或切换主题、槽位都不会重新随机排列；留出通球间隙并避开移动障碍的完整活动范围。左侧增加向内倾斜的护栏；左上与右下斜挡板保持角度，沿各自长边的斜向轴线平滑往返，碰撞位置同步移动，打开设置时一起暂停。
- 保留右侧完整发射通道、隔墙和单向回流口，去掉「惯性飞行」文字及原助推截止线。
- 左鼓和右鼓以中央鼓的竖直中线为轴，在同一高度左右镜像固定；刷新、主题和槽位切换都不改变位置。左上反弹点每命中 10 次，朝随机方向赠送一颗真实弹珠；右上反弹点每命中 10 次，将中央反弹点的外观和碰撞半径同时放大为 1.5 倍，持续 10 秒，再次触发会刷新时长。
- 中央反弹点每命中 30 次，从 12 点钟方向开始，按顺时针每 30 度发射一颗弹珠；12 颗在约 0.92 秒内依次发射完毕，可以继续碰撞、触发奖励和入槽计分。
- 左下蓄球罐通过朝上的真实入口吸收弹珠，存满 20 颗后清空本次库存，从球台顶部释放 40 颗真实弹珠。顶部开口与底部槽位一一对应，分轮随机出球，每轮覆盖所有开口，因此各开口的出球数量最多相差一颗；出球时间和位置稍有随机偏移，弹珠自然下落并参与球台碰撞、奖励及入槽计分。被存入的弹珠当时不计分，释放时每颗存球变成两颗并保留该球已有的星星倍率。库存、待发弹珠、出球口闪光都随游戏暂停；切换槽位保留库存和未发弹珠，并更新对应开口。
- 中央摆杆上方有加宽的大三格老虎机，每格独立等概率选择樱桃、柠檬、铃铛、星星、四叶草五种元素。底部槽位与秘密洞每累计进洞 50 次自动转动一次，多次达标排队保留；吸收进蓄球罐、回收与碰撞不计进洞。两格相同触发全场进洞得分 ×2，持续 3 分钟；三格相同触发 ×5，持续 1 分钟，三格不同不加成。倍率在入洞结算时生效，与单球星星倍率相乘；球台标题、各槽位和秘密洞奖励同步显示。重复中奖刷新对应时长，×5 优先，结束后恢复尚未到期的 ×2；计时、转动和队列随游戏暂停，主题与槽位切换保留，刷新页面开始新局。
- 球台和下方进度条显示三个反弹点的计数。计数在当局内累计；打开设置或切到后台会暂停奖励计时，切换槽位会取消未完成的弹珠发射序列，刷新页面开始新的一局。
- 左侧为三角弹射平台，每撞击一次便在完整 360° 范围内随机选择新角度，与上次朝向至少相差 25°，并把当前弹珠沿新方向弹出。平台尖角与箭头显示弹射方向，撞击伴随闪光、粒子和卡农音符，不吞球、不计秘密洞分数。左上斜挡板向右移动，拦截从上方向三角平台斜落的路线。
- 右侧保留带狭窄入口的秘密洞，真实进入后奖励 500 分。机会由轨迹决定，没有随机拒绝。
- 设置内选择 5、7、9 个槽位，以及动物、甜品、植物花朵主题；主题预览和切换入口仅保留在设置中，游戏主界面不显示主题卡片。
- 场内始终最多一颗小发光星星：普通金色 ×2 星星持续 30 秒，超时未拾取便销毁并换位置生成。每累计拾取 10 颗普通星星，下一颗变为紫色 ×5 星星，仅持续 10 秒，拾取或超时后恢复普通星星；紫色星星与超时不计入普通拾取次数。星星旁显示倒计时，打开设置或切到后台一起暂停。拾取后 0.5 秒出现下一颗，避开障碍物及其运动范围。拾取会将当前弹珠的结算倍率乘以星星倍率，可连续叠加；入槽与秘密洞均按本球倍率结算，其他弹珠不受影响，新弹珠从 ×1 开始。
- 入槽特效按奖励分档：×2 轻盈泡泡与双音铃声、×3 花瓣绽放与三音旋律、×5 两段星光喷泉、×10 三段金色礼花与和弦；秘密洞是四段宝藏星雨。中央 30 次碰撞触发全场最大的三秒时钟盛典，包含五段星爆、十二方向光芒、球台边框星光和专属旋律，并同步十二颗真实弹珠的发射。所有粒子和字幕绘制在活动弹珠下方；轻柔模式保留简短提示，减少粒子并禁用多段喷发与震动。
- 每个槽位按倍率计分，中央幸运槽基础分为 100 分。没有付费、赌注或兑换机制。
- 每次与障碍或墙壁的实际碰撞，依次奏出《D 大调卡农》的一个音符；没有碰撞就暂停旋律。使用公版作品的自制合成音符编排，不使用录音素材。声音在首次交互后启用，可静音或调整音量。轻柔模式减少装饰动画，默认尊重系统减少动态效果设置。
- 律动背景音乐采用原创 120 BPM 轻快放克配乐，结合稳定鼓点、切分低音、电钢琴和明亮旋律：A 段入场播放一次，再进入 B 段无缝循环。首次点击或按空格/回车后启用，切到后台暂停、返回继续；设置内可独立关闭音乐、调整音乐与音效音量，总静音键控制两者。关闭再开启音乐会继续播放，不重复入场。
- 设置内可开启「时间流逝模式」：10 分钟循环，白天 4 分钟（40%）→ 黄昏 1 分钟（10%，橙红）→ 夜间 4 分钟（40%，蓝紫）→ 清晨 1 分钟（10%，青粉）。页面、设置、球台物件与主题预览共用配色，阶段开始后的 20 秒平滑过渡；开启从白天开始，关闭恢复当前主题原色。配色时钟独立于物理模拟，设置内和切到后台仍计时；模式与起始时间保存在浏览器中，刷新、主题和槽位切换继续当前阶段。
- 设置与最高分保存在本地浏览器。打开设置或切到后台时暂停物理模拟；切换槽位会清空在途小球并保留得分。
- 手机顶部只保留与 Logo 同排的短标题，省去独立介绍与底部装饰区；球台按可用屏幕高度缩放，尽量让全局和操作区一屏显示。H5 支持触控蓄力、松手发射、取消手势、横竖屏布局和安全区。整个游戏界面禁用长按选字、图片拖动与长按菜单，同时保留页面滚动、滑块操作和浏览器缩放。

## 实现

Vite + 原生 JavaScript / Canvas + Matter.js，每秒 120 次固定步长物理模拟，渲染跟随屏幕刷新率。`src/physics.js` 管理球台与计分，`src/renderer.js` 绘制球台，`src/main.js` 管理界面和输入。`src/time-flow.js` 管理独立的昼夜时钟与颜色插值，CSS 变量、SVG 和 Canvas 共用配色；弹珠亮度和星星奖励识别色保持可辨认。`src/music.js` 用 OfflineAudioContext 本地生成原创 A/B 配乐，折叠尾音并由 AudioBufferSource 精确衔接与循环。Web Audio 实时合成弹射、弹力鼓、挡板、落袋与秘密洞音效，不依赖外部图片、字体或音频请求。应用可静态部署 `dist/`。

### 3D 球台与镜头

- 球台使用 Three.js/WebGL 构建有厚度的围栏、反弹鼓、钉子、挡板、旋转杆、槽位、凹面球洞、弹簧与球体，所有物理装置直接使用原有 Matter.js 坐标与角度。积分、星星、储球、老虎机、音乐、昼夜循环和五球蓄力均继续使用原有规则。
- 默认接近俯视，略微倾斜以显示模型厚度；横向拖动球台可左右旋转各 5°，双击回正。球台获得键盘焦点后可用左右方向键调整、Home 回正；设置内提供精确角度滑块并自动保存。镜头只影响显示，不改变弹珠轨迹。
- 移动端发射区域随镜头投影对齐；不支持 WebGL 的设备自动使用兼容画面，游戏仍可操作。模型与字体贴图均随网站打包，无远程模型加载。
- `npm run test:3d` 验证真实三维几何、坐标对应、镜头限制、触控投影、奖励放大、槽位切换时释放旧模型及兼容模式。
